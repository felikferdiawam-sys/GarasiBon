# Garasi Fotocopy - Sistem Pencatat Hutang Pelanggan

Aplikasi web pencatat hutang pelanggan berbasis Google Cloud Firebase Firestore & Firebase Hosting.

## Fitur Utama:
- ☁️ Sinkronisasi Real-Time Google Cloud Firestore (Multi-device)
- 📊 Dashboard Accordion per Pelanggan (Hanya hutang belum lunas)
- 💰 Bayar Semua (Alokasi otomatis ke nota tertua)
- 📸 Download Gambar Nota Kuitansi JPG Otomatis
- 💬 Integrasi WhatsApp (Salam otomatis pagi/siang/sore/malam)
- 📜 Riwayat Transaksi & Rekap Bulanan
- 👥 Master Data Pelanggan
